# Personal Blog Site

A Python-based personal blog website developed using Flask, SQLite, HTML, and CSS.

## Project Description

This project is a personal blog website where users can create an account, log in, and manage their own blog posts.

Users can create posts, save them as drafts, edit them, publish them, view published posts, and delete their posts.

## Features

- User Registration
- User Login and Logout
- Create Blog Posts
- Edit Blog Posts
- Save Posts as Drafts
- Publish Blog Posts
- Unpublish Posts
- View Published Posts
- Read Full Blog Posts
- Delete Blog Posts
- Personal Dashboard
- User-friendly Navigation
- SQLite Database
- Password Hashing

## Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS
